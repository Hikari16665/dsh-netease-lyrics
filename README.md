# dsh-netease-lyrics

一边用 DSH 聊天一边听网易云的时候，正在唱的那句歌词会浮在聊天内容的后面。

它不会挡到你：消息、按钮、输入框照常点，歌词只在背景里跟着歌走。效果有十种，每首歌随机挑一种，唱到一半还会自己换，所以一首歌下来不会一直盯着同一个样子。有翻译的歌会把翻译一起带上。

![十个效果总览](docs/effects.png)

## 怎么用

装上插件、刷新一次页面就好，剩下它自己来。

唯一需要你操心的只有一件事：它得往网易云里注入一个小模块，才能读到桌面歌词。插件会自己尝试注入；如果一直没看到歌词，点歌词层右下角的齿轮，面板里有「重新注入」。网易云重启之后插件会自己再注入一次，通常不用你管。

歌词层右下角有个齿轮按钮，鼠标移过去才会亮起来。点开就是设置面板，改完立刻生效 —— 不用刷新，也不用重启。

## 能用到的功能

面板里第一组是**原文和译文怎么显示**。网易云是把翻译画在原文后面的，插件只能靠推断来分辨哪句是翻译，所以给了你四种选法：翻译用小字跟在原文下面（默认）、只看原文、只看翻译，或者把原文和翻译当成前后两句歌词轮流出现 —— 最后这种配快歌看着挺带感。中文歌里连着来了两句中文的时候，也可以决定是当成两句独立歌词，还是硬当成原文加翻译。

第二组是**换场节奏**。默认每 30 秒换一次外观，一首歌里能看到好几种；也可以改成一首歌固定一套，或者每句都换。

第三组是**效果池**。十种效果都列在面板里，不想看的点掉就行，只有留下的才会被随机到。

第四组是**位置和外观**。歌词停在上中下、左中右哪一块也是自动挑的，换位置时会带一点回弹地滑过去 —— 这种活泼感可以关掉，也可以调快慢。字号、不透明度、没歌词时多久淡出、要不要在歌词下面显示歌名、玻璃化的强弱，也都在这里。

颜色会跟着 DSH 的明暗主题走，换主题不用改设置。如果你在 Windows 里关掉了动画效果，插件会自动把动效收敛成静态高亮，而不是硬给你放动画；这个行为也可以在面板里改成忽略系统设置。

## 看不到歌词的时候

先确认网易云的桌面歌词是开着的 —— 插件读的就是那个窗口。

歌词层右下角会写出当前状态：是没开桌面歌词、还是需要手动注入一次、还是网易云重启过需要重新注入，提示里都会说清楚，并且直接给你按钮。

如果连提示都看不到，多半是插件被停用了，或者页面还没刷新。

还有一种情况是歌词在，但被挡住了。歌词层在聊天面板的**后面**，面板不透明的时候就看不见；把面板里的「玻璃化」打开，它就能透出来。

## 安装和卸载

```powershell
# 从本目录安装（link: 方式，改了源码不用重装）
dsh plugin --profile web add <本目录绝对路径>

# 或者从 npm 安装（发布后）
dsh plugin --profile web add dsh-netease-lyrics
```

新装的 client 模块要刷新一次页面（F5）才会出现。

不想用了就把它停用：`dsh plugin --profile web remove dsh-netease-lyrics`，或者在设置里关掉它。

## 关于

歌词是只读的：插件不改网易云、不碰播放状态，只是把桌面歌词窗口里已经画出来的字读出来，再画到自己那一层上。为此需要往网易云注入一个小模块，这件事只做一次。
